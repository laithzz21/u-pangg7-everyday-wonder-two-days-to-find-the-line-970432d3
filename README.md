## The entry

> The lift door opened on the wrong floor, and for one second the hallway I had walked a hundred times felt like somewhere I had never been.

The most ordinary of moments — a lift stopping at the wrong floor — briefly turns a familiar hallway into an unfamiliar place. Nothing supernatural happens; the strangeness is only in how suddenly the everyday stops feeling known.

## What this does

`main.py` (Python 3.13, stdlib only, deterministic — no network, clock, or randomness) validates the entry (single sentence, 1–200 characters, plain printable ASCII, ending with a period), prints it to stdout, and also writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set, falling back to `./output/entry.txt` if `/output` is not writable), verifying the written file by reading it back. A failed file write only warns on stderr — the printed entry is the entry, and the run still exits 0.
